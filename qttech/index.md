# 量潮科技

## 定位：现行经营主体

量潮科技（qttech）是量潮体系现行的经营法人主体——数据服务与课堂业务的公司载体，第二大脑知识体系围绕它展开。战略以"产教融合"为核心竞争力：量潮数据（数据处理服务与咨询）与量潮课堂（教育创新服务与咨询）两条业务线协同，主要营收来自技术服务费。

## 核心目标：创新基础设施提供商

量潮是创新基础设施的提供商——量潮云提供生产平台，量潮课堂提供知识和经验，量潮数据提供交付能力。商业模式的核心难点在于保持经营效率，减少隐形摩擦：建立透明、开放、精细的量潮标准化体系，统一利益相关方的工作语言。

## 组织形态

公司法人，创始人主导。治理演进方向：从人治向法治转变（组织制度化），知识提炼链把经验固化为标准；远期承接主体拟演进为量潮控股（qthold）。

## 关联

- 量潮控股（qthold）：拟设的控股主体，承接治理升级
- 量潮实训基地（qtacademy）：人才培养枢纽，运营主体在科技
- 各业务线：qtdata、qtclass、qtcloud 等（见 quanttide-tech 档案体系）
