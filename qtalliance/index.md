# 量潮创新联盟

## 定位：盟友生态的组织载体

量潮创新联盟（qtalliance）是量潮盟友的展示平台与组织载体：联盟官网介绍量潮的盟友们——合作方、开发者朋友、学者朋友、执行方等生态成员在此被介绍、被看见。被量潮介绍即被验证，联盟是盟友的信用徽章。可见性系列的收官一环：代码（qtopen）→ 产品（qtproduct）→ 服务（qtbusiness）→ 研究（qtacademics）→ 盟友（qtalliance）。

## 核心目标：让盟友被看见

- **盟友目录化**：生态成员结构化收录与介绍，可检索
- **信用背书**：盟友经量潮介绍获得验证与曝光
- **生态凝聚**：让盟友被看见，形成归属感与网络

## 组织形态：三大机构

- **联盟理事会**：联盟的决策机构——定联盟方向与重大事项，理事由成员方代表出任
- **联盟代表大会**：联盟的议事机构——全体成员方代表参与，表达成员意志、审议共同事项（对应量潮议事传统中的代表大会形态）
- **联盟秘书处**：联盟的执行协调机构——承担日常运营、成员联络、活动组织与信息流转，是三大机构中唯一常设的执行层

三机构分工遵循量潮治理惯例：决策、议事、执行分离——理事会定方向，代表大会凝共识，秘书处保运转。

## 关联

- 联盟管理领域（domains/quanttide-alliance）：联盟建立、协作、治理、运营的实践方法
- 议事参照：量潮科技两院制（bylaw）与 delib 议事规则——联盟治理机制与通用议事方法衔接
- 可见性系列：qtopen / qtproduct / qtbusiness / qtacademics，盟友是收官一环
