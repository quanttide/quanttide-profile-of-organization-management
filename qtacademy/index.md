# 量潮实训基地

## 定位：串联课堂与招聘的人才培养枢纽

实训基地是量潮科技的人才培养设施——课堂与招聘双路径并行的枢纽入口，侧重于招聘向课堂逆向导流。归属组织管理（人才发展）：训练与考核的执行现场在基地完成。组织形态为内包子公司模式：学员编制在基地、按职能部门编组（技术/产品/市场/职能），承接公司业务内包任务，详见 structure.md。路径 A（课堂 → 招聘）是免费上课送实习；路径 B（招聘 → 课堂，侧重）是投递 → 准入问卷 → 选题制考核 → 通过后转课堂体系。与人事云的边界：人事云提供 HR 通用能力，基地承载训练与考核现场。

## 核心目标：让人才在真实产出中被筛选和培养

招聘筛选不出有责任心的人，责任心只能通过真实协作看出。实训基地把筛选前移到训练过程：选题制（自主发现问题 → 课题申请 → 逐轮点评迭代 → 实际产出验收），固定笔试题已淘汰。群聊沟通即训练环节（不沟通就过不了）；点评（否定+原因）是训练本身。

## 阶段方法

1. **入口上线**：双路径入口 + 准入问卷自动化（HR 零维护）
2. **考核与筛选**：选题制课题申请承担招聘考核；生产实习与试用期匹配（优秀者提供实习机会）
3. **竞争模式**："再造一个量潮"——自组队、自找角色、自竞争；生产实习标准 = 解决能力范围之外的问题
4. **收敛**：考核与课程融合（生产实习即课程）；平台内容迭代后课程业务规模化

## 数据驱动

贡献记账：训练过程中的贡献进入记账交易系统（代金券/现金奖励），表现数据支撑筛选与激励决策（表现突出者可跳过实训直接参与招聘考核）。训练群的沟通与点评记录是培养过程的事实源。

## 需求与 AI

准入问卷自动化（HR 零维护）、点评与考核记录结构化、贡献记账凭证化。明确性检验：能做出规格、写得出用户故事即明确。
