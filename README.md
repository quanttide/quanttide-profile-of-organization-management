# 量潮组织管理档案

量潮组织管理（quanttide-org）的档案库：记录组织与人物的档案，是组织域产品体系建设的核心载体。

## 结构：组织与人物两组

**一个文件夹是一个"组织"或一个"人物"**——目录即实体，`index.md` 为档案入口：

```
profile/
├── orgs/               # 组织组：一个文件夹一个组织
│   └── <org-name>/
│       ├── index.md        # 组织档案：定位、核心目标、组织形态
│       ├── structure.md    # 组织结构：部门设置与架构（可选）
│       ├── institution.md  # 制度文档：制度体系与规则约定（可选）
│       └── culture.md      # 文化文档：组织文化与气质（可选）
└── people/             # 人物组：一个文件夹一个人物
    └── <person-id>/
        └── index.md        # 人物档案：职务表、角色定位
```

## 约定

- 档案随迭代更新，反映当前理解，不追求一次写全
- 组织档案记稳定记录（定位/目标/形态），动态任务归 roadmap/journal
- 目录先于详档：新组织/新人物确定即建目录与 index.md，内容随理解深入补充
- 人物是一等实体：跨组织职务在人物档案的职务表中逐条列出；职务的单一事实源在各组织 title.md
