# 量潮研究院

## 定位：研究与创新载体

量潮研究院（qtinstitute）是量潮体系的研究组织：承载方法论的体系化研究与学术连接——把量潮在数据工程、产品研发、组织管理中沉淀的工作经验提炼为可发表、可引用、可教学的成果，并连接高校与研究者的学术网络。

## 核心目标：让经验成为研究

- **研究提炼**：工作案例 → 工作札记 → 工作手册/工程标准的提炼链，向学术成果延伸
- **学术连接**：与核心客户群（高校经管科研工作者）的双向关系——研究产生数据需求，数据服务支撑研究（与 qtacademics 呼应）

## 组织形态

拟设/筹建状态：当前研究活动分散在业务交付与课堂教学中，尚无独立组织形态。研究院是研究职能的组织化归宿，设立时机待研究体量决定。

## 关联

- 量潮学术（qtacademics）：学术黄页，研究成果的展示窗口
- 量潮数据（qtdata）：研究需求与服务供给的配对
- 量潮课堂（qtclass）：研究成果的教学转化
