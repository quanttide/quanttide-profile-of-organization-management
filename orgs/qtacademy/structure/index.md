# 量潮实训基地组织结构

量潮实训基地（qtacademy）的组织架构：**内包子公司模式**——学员编制在基地，活干在公司的业务上；按传统职能部门编组（技术、产品、市场、综合），公司结构的简化版。

## 部门编组

学员编进部门，部门是能力训练线与人员归属：

- **技术部**：研发与数据交付类任务（对应公司技术/数据交付能力）
- **产品部**：需求、设计、规格类任务
- **市场部**：增长、课程推广、招聘导流类任务（招聘逆向导流的执行面）
- **综合部**：基地自身的行政人事财务支持（最简配置）

承接内包任务时**跨部门抽人组队**：项目按任务需要从各部门抽人，任务结束回部门。部门管训练与归属，项目管交付——与公司"部门+项目"的运转方式同构，基地即真实组织的训练场。

## 实训基地秘书处：管理机构

由**公司派驻代表**组成，负责基地的管理：

- 治理与制度执行、训练与考核的组织
- 母公司管理接口：内包任务的承接对接、考核评审、**转正评审**（表现好者转正进公司编制）

## 与公司的关系：内包

公司事业部发包 → 基地部门承接（内包）→ 学员在真实任务中训练与筛选 → 转正出口进公司编制。招聘是通道出口，众包任务池是任务来源之一。

基地不复制公司治理层（无两院、无职级序列、无共享中心）——职能直接使用公司的，基地只保留交付最小集；规模扩大后再拆分部门（如技术部拆数据/课堂交付线）。
