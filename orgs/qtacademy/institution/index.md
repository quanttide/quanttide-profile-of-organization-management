# 量潮实训基地制度

量潮实训基地（qtacademy）的制度概览——基地运营章程尚未立项，本文档记录已定的制度框架与待立事项。

## 已定制度框架

**内包关系**（structure/ 的制度化表达）：

- 公司事业部向基地发包，基地部门承接——任务、验收准则、交付方式按内包约定
- 学员编制在基地，表现好者经转正评审进入公司编制——招聘是通道出口

**编组与考核**：

- 学员按职能部门编组，部门是能力训练线与人员归属；跨部门项目组按任务临时组建，部门管训练与归属，项目管交付
- 选题制考核：自主发现问题 → 课题申请 → 逐轮点评迭代 → 实际产出验收；固定笔试题已淘汰
- 准入：投递 → 准入问卷（自动化，HR 零维护）→ 进基地

**派驻治理**：

- 秘书处由公司派驻代表组成：治理、考核组织、转正评审——基地治理权在公司
- **考核评审的民主让渡**：一部分考核评审权让渡给活跃成员——他们参与自己和其他成员的考核评审。评审从派驻方单向判定走向"派驻 + 成员参与"的混合评审；这是基地民主实践的第一步，评审参与资格由活跃度（贡献记录）决定

## 待立制度（运营章程立项时补齐）

- 内包任务的定价/记账规则与贡献记账的衔接
- 实训期限、退出机制、长期实训/转学员的条件
- 成员部门内部的轮值与晋升规则
- 秘书处派驻代表的职权清单
- 成员评审团的产生与退出：活跃度标准、评审范围（哪些考核环节开放给成员评审）、评审权重与派驻评审的关系
- **不设回避**：成员参与自己的考核评审是设计而非漏洞——自我管理是量潮的核心文化，对自己结果的评审权正是自我管理的训练场；派驻评审的兜底权重用于校准而非取代成员评审
