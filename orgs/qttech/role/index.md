# 岗位档案

量潮科技（qttech）的岗位档案——一个岗位一份说明书，说明岗位的定位、职责、权限与任职资格。岗位是「槽位」：说明书描述槽位本身，不绑定具体的人。

## 结构

```text
role/
└── <role-id>.md     # 岗位说明书（英文 slug，如 secretary-general.md）
```

## 岗位清单

现有岗位为秘书长，说明书见 `secretary-general.md`，依据《量潮公司秘书章程》。

## 约定

- 岗位说明书依据章程与制度撰写，不另立规则，与章程冲突时以章程为准；
- 槽位先于人头：说明书不写现任职者，人员记录见 `structure/title.md`（职务单一事实源）；
- 新增岗位在清单中登记，岗位职责调整时同步更新说明书。
